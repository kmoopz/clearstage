ClearStage 0.1.0 — platform signing notes
=========================================

Windows: ClearStage Local Code Signing (self-signed, not a CA)
- Subject: CN=ClearStage Local Code Signing, O=ClearStage
- Thumbprint: FDEDC7F1FAA58A685DB9D2BDD967E7B8B65C1D72
- Validity: 2026-11-22 to 2029-11-22
- The installer contains ClearStage-CodeSigning.cer and imports it into
  CurrentUser\Root and CurrentUser\TrustedPublisher automatically.
- The portable ZIP contains the certificate and Install-Certificate.cmd.
- The app EXE and installer are timestamped and report "Valid" after the
  certificate is trusted.
- Windows checks the installer before the bundled certificate can be imported;
  a one-time unknown-publisher prompt is therefore still possible on first run.

macOS: ad-hoc signed, not notarized
- The .app bundle is signed with "codesign --sign -" (ad-hoc) so Gatekeeper can
  evaluate the bundle, but it has no Apple Developer ID and no notarization.
- On first open, use Finder > Open, or run: xattr -cr "/Applications/澄幕.app"
- A no-warning public distribution requires an Apple Developer account, a
  Developer ID Application certificate, and notarization.

Linux: unsigned
- The AppImage is not signed.
- If Chromium reports a sandbox error, check unprivileged user namespaces first;
  a temporary workaround is to append --no-sandbox, which weakens isolation.

Verify Windows:
  signtool verify /pa /v ClearStage-Setup-0.1.0.exe

Manual Windows certificate commands (repair only):
  certutil -user -addstore Root ClearStage-CodeSigning.cer
  certutil -user -addstore TrustedPublisher ClearStage-CodeSigning.cer
