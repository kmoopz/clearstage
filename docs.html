01 / QUICK START

快速开始

澄幕的核心只有三个动作：接入画面、观看或录制、留下切片。第一次启动时不需要账号，也不需要配置 FFmpeg。

  1. 下载并安装 Windows 版，启动澄幕。
  2. 点击右上角「添加直播间」，粘贴 https://live.bilibili.com/6 或房间号 6。
  3. 画面出现在直播台后，右侧会自动接入弹幕；点播放器下方的「录制」即可开始本地录制。
  4. 需要切片时，进入「录制库」，选择一段录制，拖动时间线起止点，导出切片。
没有安装 FFmpeg 也可以录制和按分段切片。精确切片、合并 MP4 与歌曲音频导出需要 FFmpeg；设置页会显示检测状态。
02 / INSTALL

安装与首次启动

系统要求

系统要求
WindowsWindows 10 1903+ / Windows 11，x64，4 GB 内存以上
macOS从源码构建；当前未提供签名 .dmg
Linux从源码构建；当前未提供 AppImage
磁盘建议为录制预留至少 20 GB；原画录制约 1.5–3 GB / 小时
可选组件FFmpeg 5+（精确切片、歌曲音频导出）

安装 Windows 版（推荐）

下载并运行 ClearStage-Setup-0.1.0.exe。安装程序使用当前用户权限，默认安装到 %LOCALAPPDATA%\\Programs\\ClearStage，并创建桌面与开始菜单快捷方式。安装包和主程序都已使用 ClearStage 代码签名证书签名。

0.1.0 使用的是本地自签名证书，不是 CA 证书。安装程序已内置证书并会自动导入当前用户的「受信任的根证书颁发机构」和「受信任的发布者」；便携包内也附带 ClearStage-CodeSigning.cer 和 Install-Certificate.cmd，无需再次下载。首次运行安装包时，Windows 仍可能提示未知发布者，因为证书要在安装程序启动后才能写入；选择「更多信息 → 仍要运行」即可。安装后如需手动修复，可执行：

certutil -user -addstore Root ClearStage-CodeSigning.cer
certutil -user -addstore TrustedPublisher ClearStage-CodeSigning.cer
不要只从 zip 压缩包里拖出 EXE 运行，也不要解压到带受限权限的项目目录；这会导致 Electron 沙箱无法读取安装目录，表现为“选择了仍要运行但没有反应”。请使用安装程序，或先把整个 zip 解压到桌面/用户目录。

便携版

把 ClearStage-0.1.0-win-x64.zip 完整解压到桌面或普通用户目录，再双击 ClearStage.exe。便携版同样包含已签名的主程序，设置与登录数据仍写入用户目录。

安装 FFmpeg（可选）

澄幕会先在设置路径、安装资源目录和系统 PATH 中寻找 FFmpeg。没有检测到时，可以手动安装：

# Windows（winget）
winget install Gyan.FFmpeg

# macOS
brew install ffmpeg

# Ubuntu / Debian
sudo apt install ffmpeg

安装后回到「设置 → 录制与存储」，在 FFmpeg 路径中填写可执行文件位置，或直接点「检测」。Windows 常见路径为 C:\ffmpeg\bin\ffmpeg.exe。

03 / BILIBILI

添加 B 站直播间

支持三种输入：完整链接、短号或房间号。例如：

https://live.bilibili.com/6
https://live.bilibili.com/blanc/6
6

点击「添加直播间」后，澄幕会读取房间标题、主播、封面、在线人气与开播状态，并把它加入直播台与本地收藏。再次添加同一个房间会更新信息，不会产生重复项。

纯净流指的是什么

澄幕读取平台返回的直播媒体流（HLS 或 FLV），不加载直播间网页、推荐模块、活动浮层和广告。播放请求由本机媒体代理转发，用于补齐 CDN 需要的 Referer 与 CORS 头，不经过第三方服务器。

B 站接口可能随平台调整而变化。遇到 -352 风控提示时，先在「设置」扫码登录，或在浏览器打开一次该直播间，再回到澄幕重试。
04 / DIRECT STREAM

通用直链模式

除 B 站原生直播间外，澄幕也支持接入你有权访问的通用 HLS / FLV 直播流。它适合自建推流、内网转播或你已获授权的媒体源。

  1. 在「添加直播间 → 通用直链」中，填入可访问的 HLS（.m3u8）或 FLV（.flv）直播流地址。
  2. 可填写主播名称、画面标题与必要的 Referer。点「检测」验证流格式与访问权限。
  3. 加入直播台后，该路画面支持多画面、播放与本地录制。

直链模式不提供：实时弹幕、礼物、主播资料、动态与投稿、主播数据。直链没有平台账号上下文，这些能力只在 B 站原生直播间可用。

请仅接入你拥有访问与保存权限的直播流，不要使用来源不明或侵犯他人权益的内容。澄幕不提供破解、盗播、代充值或代送礼能力。
05 / ACCOUNT

登录与弹幕

进一步访问需要你自己的 B 站账号。B 站可以在澄幕内扫码登录；观看公开 B 站画面和本地录制不需要登录。扫码登录为你自己的账号授权。

登录 B 站后可以发送弹幕、使用账号可用的更高画质、获取更完整的公开动态数据。澄幕不会用该账号执行其他操作。

  1. 打开「设置 → 账号与登录」，点击「打开扫码登录」。
  2. 用哔哩哔哩手机客户端扫码，并在手机上确认。
  3. 登录成功后会显示昵称与 UID。Cookie 使用系统安全存储加密，保存在本机。

扫码没有反应时：扫码窗口底部有「扫码失败？粘贴浏览器 Cookie」。在电脑浏览器登录 bilibili.com，按 F12 → 应用 / Application → Cookies → https://www.bilibili.com，把 SESSDATA 粘贴进去；需要发送弹幕时同时填入 bili_jct。凭证只在本机验证和加密保存。

发送弹幕

在右侧互动面板底部输入，Enter 发送，Shift + Enter 换行。B 站弹幕最多 20 个字符。发送记录会自动进入历史，可通过输入框左侧的星标收藏为常用语。

登录凭证只用于弹幕发送与改善接口访问，不会上传到澄幕服务器。退出登录会即时清除本地凭证。
06 / MULTIVIEW

多画面与布局

直播台右上角的布局切换提供 1 / 2 / 4 / 6 / 9 格。把已保存的直播间加入画面，或直接再添加一个房间。每一路画面独立维护：

  • 画质：在当前流可用的画质中选择，登录后通常可解锁更高档位。
  • 音量与静音：默认静音自动播放，点喇叭恢复声音。
  • 弹幕层：每路可单独开关；互动面板跟随当前选中的画面。
  • 录制：每路可单独开始或停止录制。

最多同时打开 9 路。实际性能取决于电脑的解码能力与网络带宽；4 路 1080p 建议至少 8 GB 内存。

07 / RECORDING

录制与文件结构

录制使用 HLS 分段写入，每约 3 秒落盘一个 TS 分段。这样做的好处是：意外退出时，已经下载的分段仍然留在磁盘上。停止录制后：

  • 生成 recording.m3u8 与 segments.json 时间线索引。
  • 检测到 FFmpeg 时自动合并为 recording.mp4，否则保留 M3U8 + TS，可用 VLC 等播放器打开。
  • 录制进入「录制库」，显示时长、大小、画质、分段数与关联切片。

目录结构

ClearStage/
├─ 20261122-143000_澄幕放映室/
│  ├─ segments/000001.ts …
│  ├─ segments.json
│  ├─ recording.m3u8
│  ├─ recording.mp4（有 FFmpeg 时）
│  └─ meta.json
├─ clips/
│  └─ 决胜团战_ab12cd.mp4
└─ songs/
   └─ 陈婧霏 - 深蓝.m4a

默认录制目录是系统「视频 / ClearStage」，可在设置中修改。删除一段录制会删除它的目录、关联切片与歌曲文件，操作前请确认。

08 / CLIPPING

时间线切片

进入「录制库 → 录制」，选择一段录制，点「切片」。用滑杆或数字输入起止秒数，填写标题，生成片段。

  • 精确切片：检测到 FFmpeg 时，从录制中以流复制方式导出 MP4，速度快、画质无损。
  • 分段切片：没有 FFmpeg 时，按覆盖所选区间的 HLS 分段拼接为 TS。边界会对齐到最近的 2–3 秒分段。

切片会保存在 录制目录/clips，可在「录制库 → 切片」查看、定位文件或删除。「标记歌曲」也复用同一条时间线，导出的是 M4A 音频。

09 / SONG CAPTURE

歌曲识别与分轨

澄幕支持两种保存歌曲的方式：自动识别与手动标记。两者都需要 FFmpeg 才能导出音频。

自动识别

  1. 在「设置 → 歌曲识别」中启用歌曲捕获，选择 AudD 或 ACRCloud。
  2. 填入对应服务的 Token 或 Host / Access Key / Access Secret，保存设置。
  3. 在录制时开启歌曲模式（歌曲识别启用后默认开启）。澄幕每约 30 秒采样一次音频；识别到切歌时，将上一首保存为独立 M4A。

识别服务由第三方提供，可能需要付费额度。密钥只保存在本机设置文件中，不会写入日志或上传到澄幕。

手动标记

在「录制库」选择一段录制，点「标记歌曲」，填写歌名、歌手与起止时间。适合没有配置识别服务、或只想保留某一首歌的场景。

自动分轨依赖外部识别准确率。遇到纯音乐、翻唱、串烧或环境噪音时可能识别不到或切分不准；重要内容建议手动标记。
10 / DANMAKU TOOLS

历史、常用与连发

成功发送的弹幕会记录在本地历史中。点输入框左侧的「历史」图标可以查看并回填；点星标可以把当前文本注入常用弹幕。

连发

在输入框工具栏点「连发设置」，选择 3–15 次与 3–10 秒间隔。澄幕会在发送过程中显示进度，可随时停止。连发只支持 B 站，且必须登录。

请遵守直播间规则，不要刷屏、引战或绕过房管。澄幕主动限制次数与最小间隔，但账号风险仍由使用者承担。

礼物与打赏

澄幕只展示公开的礼物、舰长和醒目留言数据，并用于本地礼物估算。不提供充值、代送礼或支付功能。需要打赏时请前往官方直播间完成。

11 / THEMES

主题与自定义 CSS

「风格工坊」提供夜幕、潮汐、胶片、晨雾四套主题，可独立调整强调色、弹幕字号、不透明度、礼物提示与进场提示。

高级用户可以在「自定义 CSS」中覆盖界面变量。示例：

:root {
  --radius-lg: 20px;
  --radius-md: 14px;
  --font-display: "Microsoft YaHei";
}

CSS 会立即应用到整个工作台，仅保存在本机。写错样式时清空输入框并重新应用即可恢复。

12 / INSIGHTS

主播数据如何计算

「主播数据」不是平台后台，而是澄幕在你使用期间建立的本地快照：

  • 粉丝数：来自 B 站公开关系接口。涨粉变化从你开始记录起计算。
  • 人气曲线：打开直播间时约每 60 秒采样一次，仅在澄幕运行时记录。
  • 礼物估算：来自公开弹幕中的 SEND_GIFT、醒目留言与舰长事件，按公开金瓜子价格折算，不代表平台结算流水。
  • 弹幕量：记录澄幕实际收到的直播弹幕、礼物与醒目留言数量。
数据缺失通常是因为没有打开直播间、应用未运行、接口被风控或主播未开播。切换到 7 / 14 / 30 天可查看不同窗口。
13 / FEEDS

动态与视频

选择 B 站主播后，「动态与投稿」会显示公开动态、图文和近期视频。点击「在 B 站查看」会打开系统浏览器。完整投稿列表接口偶尔受平台风控影响，此时会自动回退为动态流中的近期视频，并显示提示。

通用直链模式不提供动态与投稿，这是接入方式的边界，不是登录问题。

14 / PRIVACY

数据与隐私

澄幕没有云端账号系统，也不含遥测或广告。默认数据位置：

内容位置
设置、直播间、录制索引、数据快照系统应用数据目录 ClearStage/clearstage.json
B 站登录 CookieClearStage/bili-cookies.bin，使用系统安全存储加密
录制、切片、歌曲默认 视频/ClearStage，可在设置中修改

删除应用数据目录会清除设置与登录状态；删除录制目录会移除媒体文件。澄幕不会自动上传这些文件。

15 / TROUBLESHOOTING

故障排查

画面黑屏 / 一直显示「正在接入纯净流」

  • 确认主播正在直播，而不是轮播或下播状态。
  • 点播放器右上角刷新按钮；直播流地址有有效期，澄幕会重新解析。
  • 在浏览器打开一次该直播间，再回来重试。
  • B 站接口可能触发风控，尝试扫码登录后再解析。

弹幕显示「受限」或连接失败

  • 房间可能关闭了弹幕，或主播未开播。
  • 弹幕服务器需要 WBI 签名；澄幕会自动刷新签名，但遭遇 -352 时请稍后重试或登录。
  • 检查网络是否阻止了 wss://*.chat.bilibili.com。

录制失败或没有声音

  • 检查录制目录是否有写入权限和足够空间。
  • 确认直播流没有启用加密；加密流暂不支持录制。
  • 停止后如果没有 MP4，查看是否安装 FFmpeg；M3U8 + TS 仍然可用。

切片失败

  • 没有 FFmpeg 时会回退为分段切片，边界可能偏移 2–3 秒，这是预期行为。
  • 选择的起止时间需要至少间隔 0.5 秒。
  • 如果录制仍在进行，等停止并完成合并后再做精确切片。

扫码登录失败

  • 二维码三分钟过期，点「重新生成」。
  • 确认手机端已点确认，而不是只完成扫码。
  • 如果扫码后状态一直不变化，改用「扫码失败？粘贴浏览器 Cookie」：从已登录的浏览器复制 SESSDATA 与 bili_jct，应用会用 B 站 nav 接口验证后再保存。
  • 若系统安全存储不可用，应用会回退为本地文件保存；可在「数据与关于」确认应用数据目录。

Windows 提示未知发布者，或“仍要运行”没有反应

0.1.0 使用本地自签名证书，证书已内置在安装包中，安装程序会自动导入。首次运行未受信任的安装包时，Windows 仍可能提示未知发布者（证书要在安装程序运行后才生效）；安装完成后主程序会被识别。若安装后仍提示，可运行安装目录中的 Install-Certificate.cmd，或从官网下载证书手动导入。若点击“仍要运行”后没有窗口，通常不是签名问题，而是把 EXE 单独从 zip 拖出，或解压到了权限受限的目录，导致 Electron 找不到 resources / 无法读取安装目录。请使用安装程序，或将整个 zip 解压到桌面等普通目录后运行。

16 / SOURCE BUILD

源码构建

澄幕基于 Electron + React + TypeScript。源码构建需要 Node.js 22+ 与 npm。

# 获取源码后
npm install
npm run dev          # 开发模式
npm run typecheck    # 类型检查
npm test             # 单元测试
npm run build        # 构建渲染层与主进程
npm run package:win  # 打包 Windows 版本（electron-builder）

macOS / Linux 可分别执行 npm run package:mac 与 npm run package:linux（需要对应平台的构建环境）。打包配置已写在 package.json 的 build 字段。

当前公开下载提供已签名的 Windows 安装包与便携包。签名是 ClearStage 本地自签名证书，不是 CA 证书；跨电脑分发前，请让用户安装附带的证书。macOS / Linux 仍未签名、未公证，因此官网不提供直接下载。
