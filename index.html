01 THE POINT

不是把网页塞进播放器，
而是为你重新安排一块屏幕。

直播本来有很多层：画面、弹幕、礼物、回放、主播的过去与此刻。大多数时候，它们被拆散在标签页、客户端和本地文件夹里。 澄幕把它们收拢到桌面，但不打扰你正在看的东西。

THE WORKFLOW

从进入直播间，
到留下一个片段。

不需要先学一套复杂的直播工具。澄幕只把必要的动作放在手边，其他都留在背景里。

01

接入一路画面

粘贴 B 站直播间链接或房间号；也可以接入你有权访问的通用 HLS / FLV 直链。画面进入直播台，B 站弹幕同时开始工作。

02

看着，或让它录着

点一下录制，HLS 分段就会写入你选择的目录。离开直播台也不会中断；停止后自动进入录制库。

03

在时间线上留下想要的

拖动起止点导出切片；开启歌曲捕获后，切歌会自动保存成独立音频。所有文件都在本地。

LOCAL ARCHIVE

没有云端上传，也没有二次压缩。你录下的，就是你看到的。

AFTER THE STREAM

直播结束，
数据还留在这里。

澄幕会在你观看期间记录粉丝、在线人气与公开礼物事件，形成一条只属于你的本地时间线。它不替代平台后台，但足够回答「这一场到底发生了什么」。

LOCAL FIRST, BY DEFAULT

你的直播，
不必经过我们的服务器。

播放流由本机媒体代理转发，录制、切片、歌曲与数据都写入本地目录。澄幕没有云端账号体系，也不含遥测和广告。你唯一需要联网的时刻，是平台接口本身。

01 澄幕需要登录吗？不登录能看吗？

观看公开画面和录制不需要登录。使用更高画质、发送弹幕、访问更完整的动态与数据时，需要从已登录的浏览器复制 B 站 Cookie，在设置页导入。登录 Cookie 仅保存在本机。

02 通用直播直链支持哪些能力？

通用 HLS / FLV 直链支持播放、多画面与本地录制、时间线切片。由于直链没有平台账号上下文，无法提供实时弹幕、礼物、主播资料、动态或主播数据。

03 没有安装 FFmpeg 会影响什么？

基础录制与「按分段对齐」的切片仍然可用。精确到帧的切片、自动合并 MP4、歌曲音频导出需要 FFmpeg。安装后在「设置 → 录制与存储」中检测即可。

04 Windows 提示「未知发布者」怎么办？

0.1.0 使用 ClearStage 本地自签名证书。当前电脑已安装信任，可直接运行安装包；其他电脑若提示未知发布者，请安装下载页的 ClearStage-CodeSigning.cer 到「受信任的根证书颁发机构」与「受信任的发布者」。请勿在压缩包内直接双击 EXE，也不要把程序解压到受限项目目录。

05 录制文件在哪里？会占很多空间吗？

默认在系统「视频/ClearStage」目录，可在设置中更改。录制按 HLS 分段写入，画质越高占用越大；录制库会显示每段的大小与总占用。删除录制会同时删除关联切片与歌曲文件。
